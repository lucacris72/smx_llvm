# LLVM Project Base

The vendored `llvm-project/` tree was imported from:

```text
Repository: https://github.com/llvm/llvm-project.git
Branch: release/18.x
Commit: 3b5b5c1ec4a3095ab096dd780e84d7ab81f3d7ff
```

The nested LLVM `.git` directory is not part of this repository. This keeps
`llvm-project/` as normal tracked source files, so SMX changes can be committed
directly in the same repository.
